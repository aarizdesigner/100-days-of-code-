37 Days of C Programming - C SOURCE FILES ONLY

Each Day_XX folder contains two .c source files.
Open the folder in Visual Studio Code and compile/run the required question.

Example with GCC:
  gcc Q01.c -o Q01
  ./Q01

On Windows PowerShell after installing GCC/MinGW:
  gcc Q01.c -o Q01.exe
  .\Q01.exe

Note: Each question is a separate C program because every file has its own main() function.
